# K-nearest-neighbors

ตัวอย่างอัลกอริทึม k-NN แบบเขียนเองด้วย NumPy ตามโจทย์ในสไลด์
ข้อมูล 9 จุด แบ่งเป็น 3 กลุ่มสี (blue, green, red) และทายว่าจุด X = (5, 5) อยู่กลุ่มไหน

## ติดตั้ง
```bash
pip install numpy
```

## วิธีใช้งาน
```bash
python knn_find.py
```
โปรแกรมจะแสดงผลการทายเมื่อใช้ k = 1, 3 และ 6

## ข้อมูลที่ใช้
| กลุ่ม | จุด |
|---|---|
| blue | (4, 5), (3, 6), (2, 5) |
| green | (6, 6), (5.5, 6.2), (7, 7) |
| red | (5, 3.2), (4.2, 3.5), (5, 2) |

## หลักการทำงาน
1. คำนวณระยะ Euclidean จากจุด X ไปทุกจุด
2. เรียงระยะจากน้อยไปมาก แล้วเลือก k จุดที่ใกล้ที่สุด
3. โหวตกลุ่มที่พบมากที่สุด (majority vote) เป็นคำตอบ

## ลองแก้ได้
- เปลี่ยนจุดที่จะทายที่ตัวแปร `X_target`
- เปลี่ยนค่า k ที่ตัวแปร `k_list`
